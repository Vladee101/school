# ADR 0006. PDF в Vercel Blob с прямой загрузкой из браузера

**Статус:** Принято

## Контекст
На Vercel нет постоянной файловой системы, а тело запроса к функции ограничено примерно 4,5 МБ. Документы публичные и
должны открываться без входа.

## Решение
- Файлы хранятся в публичном хранилище Vercel Blob.
- Браузер загружает файл напрямую в Blob по клиентскому токену, который выдаёт [/api/blob/upload](../../src/app/api/blob/upload/route.ts)
  только администратору: допустим тип `application/pdf`, до 20 МБ, добавляется случайный суффикс имени.
- В БД хранится URL. Сервер перед сохранением проверяет, что URL указывает на домен Blob и оканчивается на `.pdf`, поэтому
  подмена адреса в форме не пройдёт.
- При замене или удалении документа файл удаляется из Blob (ошибка удаления логируется, но не ломает операцию).

## Последствия
- Файлы публичны по ссылке: нельзя хранить через этот механизм конфиденциальные документы.
- Если загрузка прошла, а форма не сохранена, в Blob остаётся «сирота»; для масштаба школы это приемлемо.
