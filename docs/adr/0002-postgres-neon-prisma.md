# ADR 0002. PostgreSQL (Neon) и Prisma

**Статус:** Принято

## Контекст
В ТЗ есть связи, ограничения целостности и атомарное сохранение результата (результат, 20 ответов, доминирующие типы).
Vercel не хранит файлы между запросами, поэтому SQLite в файле не подходит.

## Решение
- PostgreSQL в Neon (бесплатный тариф, интеграция с Vercel).
- Prisma 7 с драйвер-адаптером `@prisma/adapter-pg`; клиент генерируется в `src/generated` (не коммитится, создаётся в `postinstall`).
- Приложение использует pooled-адрес (`-pooler`), миграции идут напрямую: [prisma.config.ts](../../prisma.config.ts)
  убирает `-pooler` из `DATABASE_URL`, либо берёт `DIRECT_URL`.
- Целостность, которую Prisma не выражает, добавлена SQL в миграцию: `CHECK` суммы пяти шкал = 20 и неотрицательности баллов,
  `CHECK` дня недели 1..7.
- Несколько доминирующих типов хранятся связующей таблицей `result_dominant_types`, а не строкой.

## Последствия
- Целостность результата защищена и на уровне БД, а не только кодом.
- Миграции нужно применять отдельно от деплоя (`npm run db:deploy`).
- Версия Prisma закреплена на 7.10.1: `latest` на момент работы была релиз-кандидатом 8.
