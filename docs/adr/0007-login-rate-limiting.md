# ADR 0007. Ограничение попыток входа через таблицу в БД

**Статус:** Принято

## Контекст
Без ограничения пароль можно подбирать. В serverless счётчик в памяти не работает: экземпляры функций не разделяют состояние.

## Решение
Таблица `login_attempts` (ключ `l:<логин>` или `i:<ip>`, время). Вход блокируется на 15 минут после 5 неудач для логина или
30 неудач для IP ([src/lib/rate-limit.ts](../../src/lib/rate-limit.ts)). Успешный вход сбрасывает счётчик логина. Старые записи (старше суток)
удаляются при записи новой неудачи, отдельный планировщик не нужен.

## Последствия
- Посторонний может на 15 минут заблокировать чужой логин, подбирая пароль (принятый компромисс).
- IP берётся из `x-forwarded-for`, за общим NAT школы лимит по IP (30) разделяют все ученики с одного адреса.
- Лимит смены пароля не добавлен: для неё нужна уже авторизованная сессия.
